About This Dashboard

This dashboard tracks 27 key statewide outcomes across 12 policy areas using federal data sources. All metrics use the same methodology for all 50 states, enabling apples-to-apples comparison. The dashboard is nonpartisan and reports outcomes, not government activity.

Methodology Notes

  • Comparator definition. "Other State Average" is the unweighted mean of all 49 other states, excluding Hawaii. Washington D.C. is not included.
  • Data currency. Each metric shows its latest available year. Federal sources publish on different schedules, so not all metrics share the same data vintage.
  • Series breaks. The Census ACS broadband variable (B28002) changed definition in 2016, so pre-2016 broadband data is excluded from this dashboard. County-level Per Capita Income uses RPP-adjusted (cost-of-living adjusted) values from BEA, which differ from the nominal values shown in the state-level detail view.
  • Missing years. 2020 ACS data is excluded for most Census-sourced metrics due to COVID-related collection disruptions that compromised data quality.
