Preview · Item 5 (copy brief leads with tier)

Modal "Copy brief" output

The paragraph generated when a user clicks Copy brief in any metric modal. Used by grant writers, board reports, and program briefs. Today the lead sentence opens with the metric value and tacks rank at the end. Proposal: lead with the tier verdict, then the value, so the funder reads the categorical evidence first and the number as backup. Everything else stays.

What changes

  • Lead sentence: rewires from "{intro}, ranking #N nationally" to "Hawaiʻi is in the {Tier} nationally (#N of 50). {intro}".
  • Trend, median comparison, caveat: unchanged.
  • The "Bottom line:" frame: still used. Familiar pattern for execs and grant writers.
  • Tier vocabulary: same Top / Middle / Bottom tier from the cards. Utils.rankTierLabel() is the single source of truth.
