Preview · Item 1 (5-year change tier on cards)

Card vsYear verdict: tier word vs. verb + percent

The lower-left comparison block on each home-page card. Today it reads improved 5.2% / worsened 2.1% / held steady. After: a single categorical word — Improving / Flat / Worsening — drawn from the same direction-aware logic as the rank-tier block on the right, with a ±5% Flat band. The magnitude moves to the tooltip.

What changes

  • Verdict text: improved 5.2% → Improving   ·   worsened 2.1% → Worsening (or Flat if <5%)   ·   held steady → Flat
  • Flat band: widens from ±0.5% to ±5%. Anything below the new threshold reads Flat instead of "improved 1.8%" or "worsened 2.4%".
  • Tooltip: gains the magnitude (e.g., "2020-24 window vs 2017-21 window (improved 12.4%)") so the number stays accessible to anyone who hovers.
  • What does NOT change: the year-range label (2020-24 vs 2017-21), the green/grey/red color, the 3-year-rolling-window mechanic, or the rank-tier block on the right.
